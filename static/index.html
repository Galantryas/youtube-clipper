Step-by-Step Setup & Token Guide
Learn how YouTube tokens work & how to connect permanent credentials
▼
Access Token ⏱️ 1 Hour (Auto-Refreshed)
Refresh Token ♾️ Permanent (In Production)
Required Scope youtube.upload
1
Create OAuth Client ID in Google Cloud
Enable YouTube Data API v3 in Google Cloud, then under Credentials create an OAuth Client ID (Web application).
↗ Open Google Cloud Console
2
Set Consent Screen to "In Production" Crucial
Under OAuth consent screen, click PUBLISH APP to switch from Testing to In production. This prevents Google from expiring your refresh token after 7 days.
3
Generate Tokens in OAuth Playground
In Google OAuth Playground, click ⚙️ Gear → check "Use own OAuth credentials" → paste your Client ID & Secret. Select https://www.googleapis.com/auth/youtube.upload, authorize, and click Exchange authorization code for tokens.
↗ Open OAuth Playground
4
Save Refresh Token in YouTube Clipper
Paste your Refresh token (starts with 1//0...), Client ID, and Client Secret into the form above and click 💾 Save YouTube Auth.

Step-by-Step Setup & Token Guide
How TikTok rolling 365-day tokens work & setup commands
▼
Access Token ⏱️ 24 Hours (Auto-Refreshed)
Refresh Token 🔄 365 Days (Rolling Renewal)
Required Scopes user.info.basic, video.publish
1
Create App in TikTok for Developers
Go to TikTok Developers, add Login Kit and Content Posting API. Add https://oauth.pstmn.io/v1/callback to Redirect URIs. Under Target/Test Users, add your TikTok account username.
↗ Open TikTok Developers
2
Authorize in Web Browser
Open the authorization link below (replace YOUR_CLIENT_KEY), click Authorize, and copy the code from the redirected address bar:
https://www.tiktok.com/v2/auth/authorize/?client_key=YOUR_CLIENT_KEY&scope=user.info.basic,video.upload,video.publish&response_type=code&redirect_uri=https%3A%2F%2Foauth.pstmn.io%2Fv1%2Fcallback&state=123
3
Exchange Code for Tokens in PowerShell
Run this PowerShell command to exchange the code for your tokens:
$body = @{ client_key="YOUR_KEY"; client_secret="YOUR_SECRET"; code="YOUR_CODE"; grant_type="authorization_code"; redirect_uri="https://oauth.pstmn.io/v1/callback" }; Invoke-RestMethod -Uri "https://open.tiktokapis.com/v2/oauth/token/" -Method Post -Body $body
4
Save in YouTube Clipper Pro
Paste the access_token (starts with act.) and refresh_token (starts with rft.) above. The rolling token will renew itself automatically whenever used!

Step-by-Step Setup & Token Guide
How Meta 60-day auto-renewing tokens & account IDs work
▼
Short-Lived Token ⏱️ 1-2 Hours
Long-Lived Token 🔄 60 Days (Auto-Renewing)
System User Token ♾️ Never Expires
1
Prerequisites: Professional Instagram & Facebook Page
Instagram Content Publishing requires an Instagram Business or Creator account linked to a Facebook Page.
2
Create Meta App & Generate Token in Explorer
In Meta Graph API Explorer, select your App → Add permissions: instagram_basic, instagram_content_publish, pages_show_list, pages_read_engagement. Click Generate Access Token.
↗ Open Meta Graph API Explorer
3
Find your Instagram Business Account ID
In Explorer, run GET /me/accounts to get your Page ID, then run GET /{PAGE_ID}?fields=instagram_business_account. Copy the 17-digit numeric id.
4
Save Credentials for 60-Day Auto-Renewal
In your Meta App Dashboard under App Settings → Basic, copy your App ID and App Secret into the form above. YouTube Clipper Pro will automatically keep your 60-day token active!
↗ Open Meta App Dashboard
